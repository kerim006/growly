# Growly

Growly is a lightweight client-side [Fabric](https://fabricmc.net/) mod that makes checking crops quick and effortless. Simply look at a crop to see its exact growth percentage displayed above it.

The label changes color at a glance to show each crop's current stage:

- **Red** for early growth
- **Gold** while growing
- **Green** when ready to harvest

## Build

```bash
./gradlew build
```

On Windows, run `gradlew.bat build`. The built mod will be placed in `build/libs`.

## Installation

Install Fabric Loader and Fabric API, then copy the Growly JAR into your Minecraft `mods` folder.
